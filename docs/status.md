# 实现状态与验收边界

本工程处于基础闭环开发阶段，不应作为正式输入法发行。完整产品要求以工程内的 [芝麻输入法设计方案](design.md) 为准；该方案描述目标能力，本页记录当前实现与缺口。

## 接口

C ABI 声明位于 `include/zhima.h`。句柄只允许串行调用，字符串由库分配和释放。`zf_test_key` 无状态变更；`zf_process` 返回 JSON 快照；`zf_ack_commit` 仅在文本提交成功后学习。空句柄、非法 UTF-8 和内部 panic 返回失败结果；无效内存指针不是合法输入。

## 数据

索引格式：`ZFIM` 魔数、版本字节、u64 小端数据长度、u64 小端 FNV-1a 损坏检测值、JSON 记录。校验值不提供真实性保证。TSV 列为文本、编码、非负词频、可选规范全码。数据顺序决定五笔同码顺序。

SQLite 首版迁移使用事务，拒绝未来版本；后续版本迁移前仍需增加自动备份和恢复。配置保存采用同目录临时文件替换，尚不支持多个设置进程并发保存。

## 后续必需工作

1. 完整词库引入、来源与许可证锁定、规范全码校验、重复项报告及导入预览。
2. 音节 Trie、末音节合法性和切分路径预算；消除词典扫描。
3. 后台持久化与快照、配置热切换、全部设置生效。
4. Windows TSF x86/x64 前端、带用户权限限制的服务 IPC；Linux 双框架适配与包构建。
5. 三端真实安装测试、故障测试、签名公证、升级回退和性能测量。

尚未完成项没有用空实现或成功返回值伪装为可用功能。
